# 이두현의 Travel Log (너는 어디까지 가봤니?)

**이두현의 Travel Log**는 전 세계 해외 국가와 대한민국 세부 행정구역(시·군·구)의 여행 기록, 위시리스트, 사진 추억을 시각적으로 기록하고 관리할 수 있는 인터랙티브 여행 지도 웹 애플리케이션입니다.

---

## 주요 기능

### 1. 인터랙티브 세계 지도 & 국내 지도
* **기본 구형 3D 지구본 (Globe)**: 첫 화면에서 몰입감 있는 구형 지구본 형태로 전 세계 지도를 조작할 수 있습니다.
* **평면 지도 전환 (펼치기/접기)**: 우측 상단의 **「펼치기」** 버튼을 눌러 평면 종이 지도 형태로 전환하거나, **「접기」** 버튼을 눌러 다시 구형 지구본으로 돌아올 수 있습니다.
* **국내 세부 지역 지원**: 단순 광역시·도 17개를 넘어 80여 개 이상의 세부 시·군·구(강릉, 속초, 여수, 전주, 송도, 제주 등) 단위로 여행 기록을 세분화하여 관리가 가능합니다.

### 2. 여행 상태 및 방문 횟수 관리
* **방문 완료 / 위시리스트**: 클릭 한 번으로 방문한 지역 또는 방문하고 싶은 위시리스트로 등록할 수 있습니다.
* **방문 횟수 카운터**: 동일한 지역을 여러 번 방문한 경우 방문 횟수를 (+ / -) 조절할 수 있으며, 방문 횟수가 많을수록 지도의 색상이 점점 진해집니다.
* **필터 및 검색**: 대륙별(아시아, 유럽 등) / 국내 도별 필터 및 한글/영문 실시간 검색 기능을 제공합니다.

### 3. 추억 사진 등록 및 관리
* **방문 횟수 비례 업로드**: 방문 완료한 지역에는 방문 횟수(최대 5장)만큼 여행 사진을 업로드할 수 있습니다.
* **클라이언트 자동 압축**: 8K/4K 고화질 원본 사진도 안전하게 클라이언트 측에서 크기를 최적화하여 보관합니다.

### 4. 테스트용 계정 지원
* **즉시 체험 모드**: 로그인 창 내 **「테스트용 계정으로 접속」** 버튼을 통해 별도 회원가입 없이 바로 지도 클릭, 방문 처리, 사진 업로드 기능을 테스트할 수 있습니다. (테스트 계정은 접속 종료 시 자동 초기화)

## 디자인 컨셉
* **Warm Natural & Olive Sage 톤**: 편안하고 차분한 웜 세이지/올리브 그린과 크림 베이지 톤을 조합하여 잡지 느낌의 고풍스러운 수집 노트를 연출하였습니다.
* **Display Typography**: 구글 가라몬드 스타일의 Serif 폰트와 깔끔한 Sans-serif를 조합하여 매력적인 여행 폰트를 제공합니다.

## 기술 스택

* **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
* **Data Visualization**: D3.js (`d3-geo`, `d3-selection`, `d3-zoom`), Lucide React Icons
* **Backend & Storage**: Firebase Authentication, Firestore, Firebase Storage
* **Image Processing**: Client-side Canvas Compression

## 시작하기

### 개발 서버 실행
```bash
# 패키지 설치
npm install

# 개발 서버 실행 (Port 3000)
npm run dev
```

```bash

npm run start
```
